# Manometer Agent

The program that places bets on the account holder's accounts: placement, read-back of the ticket, limits, reports.

**No code here yet.** The Agent is published with release 1, after cleaning and a security review: no secrets, no account data, no history. See https://manometer.bet/open-source.html for the plan.
