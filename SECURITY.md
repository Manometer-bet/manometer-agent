# Security

Please report vulnerabilities privately: use the contact form on https://manometer.bet/about.html#contact with the subject "Security", or email office@email.de.

Do not open a public issue for a vulnerability. We answer every report, credit the finder if they wish, and do not pursue good-faith research.

The Agent places bets with real money, so these reports come first: anything that lets the bridge or a web page make it do more than place a signed bet within its limits, and anything that sends more than `PHONE_HOME.md` lists.
